# sonlinevote
서울온라인학교 캐릭터 공모전 투표 서비스입니다.

학생들이 그린 캐릭터 작품을 갤러리로 보여 주고, 학생은 로그인한 뒤 **하트(좋아요)** 와 **댓글**로 투표합니다.
선생님은 `admin.html`에서 작품을 올리고, 투표를 시작·마감하고, 결과를 엑셀용 CSV로 내려받습니다.

- 프론트: HTML + CSS + 순수 JavaScript (빌드 도구 없음)
- 백엔드: Supabase (데이터베이스 + 이미지 저장소 + 로그인)
- 배포: GitHub Pages

## 2. Supabase 설정 (처음 한 번)

> Supabase 프로젝트: **db_hyunuk** (`https://ljrdiibfskstlcggoyyg.supabase.co`)

### 2-1. 데이터베이스 만들기
1. [Supabase 대시보드](https://supabase.com/dashboard)에 로그인 → **db_hyunuk** 프로젝트를 엽니다.
2. 왼쪽 메뉴 **SQL Editor** → **New query**.
3. `supabase/schema.sql` 파일 내용을 **전부** 복사해 붙여넣고 **Run**.
4. 아래쪽에 `Success. No rows returned`가 나오면 성공입니다.
   - 표, 보안 정책(RLS), 이미지 저장소(`artworks` 버킷), 함수가 한 번에 만들어집니다.
   - 나중에 다시 실행해도 데이터는 지워지지 않습니다.

### 2-2. 학생 로그인(익명 로그인) 켜기 — 필수
학생은 이메일 없이 학교·학번·이름만으로 참여합니다. 이를 위해 내부적으로 "익명 로그인"을 씁니다.
1. **Authentication → Sign In / Providers**
2. **Allow anonymous sign-ins** 를 켜고 저장.

### 2-3. 익명 로그인 횟수 제한 늘리기 — 필수
기본값은 **IP 하나당 1시간에 30번**입니다. 학교에서는 여러 학생이 같은 와이파이(같은 IP)를 쓰므로 31번째 학생부터 로그인이 막힙니다.
1. **Authentication → Rate Limits**
2. **Rate limit for anonymous users** 값을 참여 학생 수보다 넉넉하게(예: 1000) 올리고 저장.

### 2-4. 이메일 인증 끄기 — 권장
관리자 계정을 만들 때 인증 메일을 기다리지 않도록 합니다. (이 사이트는 가입 코드로 바로 활성화하므로 인증 메일이 필요 없습니다.)
1. **Authentication → Sign In / Providers → Email**
2. **Confirm email** 끄기 → 저장.

> 켜 두어도 동작은 하지만, Supabase 기본 메일 발송 한도(시간당 몇 통)에 걸려 계정 만들기가 실패할 수 있습니다.

### 2-5. 첫 관리자 계정 만들기 (둘 중 하나)
**방법 A — 화면에서 (가장 쉬움)**
1. 사이트의 `admin.html`을 엽니다. (3장 또는 4장을 먼저 진행)
2. **관리자 계정 만들기** 탭 → 이메일, 비밀번호(6자 이상), 가입 코드 `sonline` 입력.
3. 계정 생성 → 활성화 → 관리자 등록 → 로그인이 한 번에 됩니다.

**방법 B — SQL로 미리 만들기**
1. SQL Editor에 `supabase/create_admin.sql` 내용을 붙여넣습니다.
2. `'여기에_이메일'`, `'여기에_비밀번호'` 두 곳만 실제 값으로 바꾸고 **Run**.
3. ⚠️ 실제 비밀번호를 넣은 파일은 GitHub에 올리지 마세요.

### 2-6. 관리자 가입 코드 바꾸기 — 권장
기본 코드 `sonline`은 이 README에 적혀 있어 누구나 볼 수 있습니다. 운영 전에 꼭 바꾸세요.
```sql
update public.secrets set value = '새로운코드' where key = 'admin_signup_code';
```
이 코드는 데이터베이스에만 저장되며 브라우저에서는 읽을 수 없습니다.

### 2-7. 연결 정보 확인
`js/config.js`에 이미 db_hyunuk 프로젝트의 주소와 **anon(공개) 키**가 들어 있습니다.
다른 프로젝트로 바꿀 때는 **Project Settings → API**(또는 Data API)에서
- **Project URL** (끝에 `/rest/v1/` 없이)
- **anon public** 또는 **publishable** 키
를 복사해 넣으면 됩니다.

> ⚠️ **service_role** 키나 **secret** 키는 절대 넣지 마세요. 모든 보안을 무시하는 열쇠라서, 공개된 코드에 들어가면 누구나 데이터를 지울 수 있습니다.

## 3. 내 컴퓨터에서 테스트하기
파일을 더블클릭해 `file://`로 열면 일부 기능이 동작하지 않을 수 있습니다. 간단한 웹 서버로 여세요.

**방법 1 — Python (윈도우·맥 모두)**
```bash
cd sonlinevote          # 이 폴더로 이동
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` (학생 화면), `http://localhost:8000/admin.html` (관리자).

**방법 2 — VS Code**
확장 프로그램 **Live Server** 설치 → `index.html`에서 마우스 오른쪽 → **Open with Live Server**.

**확인 순서**
1. `admin.html` → 관리자 로그인 → **작품** 탭에서 이미지 1~2장 올리기.
2. **대시보드**에서 투표 스위치 켜기.
3. 학생 화면에서 로그인 → 하트 → 댓글 → 관리자 **댓글** 탭에서 실명으로 보이는지 확인.
4. 시크릿 창(다른 기기 역할)에서 같은 학교·학번·이름으로 로그인 → 원래 창에서 하트를 누르면 "다시 로그인" 안내가 나오는지 확인.

## 5. 운영하기 (공모전 진행 순서)

### ① 작품 올리기 (관리자 → 작품 탭)
1. **작품 정보 CSV 불러오기**: `작품정보.csv`를 엑셀로 열어 신청서 내용(제목, 출품자, 설명)을 채운 뒤 선택합니다.
   - 열 순서: `제목, 출품자, 설명, 파일명키워드`
   - **파일명키워드**: 이미지 파일 이름 안에 들어 있는 글자. 예) 키워드 `작품3` ↔ 파일 `작품3_구름토끼.png`
   - 엑셀에서 저장할 때는 **CSV UTF-8(쉼표로 분리)** 형식을 권장합니다. (일반 CSV로 저장해도 한글을 자동으로 맞춰 읽습니다)
2. 이미지를 상자에 **끌어다 놓기**(여러 장 가능). 키워드가 맞으면 "CSV 매칭됨"으로 자동 채워지고, 아니면 드롭다운에서 고르거나 직접 입력합니다.
3. **모두 업로드**. 큰 이미지는 자동으로 줄여서 올립니다(끌 수 있음).
4. 아래 **등록된 작품** 목록에서 내용 수정, **숨기기**(학생 화면에서 감춤), **삭제**(이미지 파일까지 삭제)를 할 수 있습니다.

### ② 문구 설정 & 투표 시작 (대시보드)
- 사이트 제목·안내문을 고치고 **저장**.
- **투표 상태 스위치**를 켜면 바로 투표가 시작됩니다. 끄면 마감되어 학생은 보기만 할 수 있습니다.

### ③ 진행 중 관리
- **학생 탭**: 로그인한 학생 목록, 검색, 기기 연결 해제, 프로필 삭제(하트·댓글 포함), CSV.
- **댓글 탭**: 실제 이름·학번과 함께 보기. 부적절한 댓글은 **숨기기**(기록은 남김) 또는 **삭제**.

### ④ 마감 & 결과
1. 대시보드에서 스위치를 꺼 투표를 마감합니다.
2. **결과 탭**: 하트 순위표(같으면 공동 순위) + CSV 3종
   - 작품별 집계 / 하트 상세(누가 어느 작품에) / 댓글 상세
   - 모두 엑셀에서 한글이 깨지지 않게 저장됩니다.

### ⑤ 개인정보 파기 (결과 확정 후)
로그인 화면에서 "결과 확정 후 파기"를 안내했으므로, 결과 CSV를 보관한 뒤 SQL Editor에서 실행하세요.
```sql
-- 학생 프로필 삭제 (하트·댓글도 함께 삭제됨)
delete from public.students;
-- 학생 익명 로그인 계정 정리
delete from auth.users where is_anonymous = true;
```

## 6. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| 학생 로그인 시 "익명 로그인이 꺼져 있습니다" | 2-2. Anonymous sign-ins 켜기 |
| 30명쯤부터 "요청이 너무 많습니다" | 2-3. 익명 로그인 Rate Limit 올리기 |
| "이미 다른 이름으로 등록된 학번입니다" | 같은 학교·학번에 다른 이름이 이미 있음. 오타라면 관리자 → 학생 탭에서 해당 프로필을 삭제 후 다시 로그인 |
| 하트를 누르면 "다른 기기에서 로그인되어…" | 같은 학번으로 다른 기기에서 로그인해 연결이 옮겨감(정상 동작). 이 기기에서 다시 로그인하면 됨 |
| 관리자 로그인 후 "관리자로 등록되지 않은 계정" | 가입 코드로 등록하지 않은 계정. **관리자 계정 만들기**에 같은 이메일·비밀번호·코드를 입력하면 등록됨 |
| "이메일 인증이 안 된 계정" | 위와 같이 **관리자 계정 만들기**에서 같은 정보로 다시 입력하면 활성화됨. 2-4도 확인 |
| 계정 만들기에서 "rate limit" 오류 | 2-4. Confirm email 끄기 |
| 작품 업로드 실패 (권한) | 관리자로 로그인했는지, schema.sql을 실행했는지 확인 |
| 작품 업로드 실패 (용량/형식) | 1장 10MB 이하, PNG·JPG·WEBP·GIF만 가능 |
| 화면에 "사이트 설정(js/config.js)이 비어 있거나…" | `js/config.js`의 URL·키 확인. 인터넷 연결 확인 |
| 고친 내용이 사이트에 안 보임 | main 브랜치에 올렸는지 확인, 1~2분 후 `Ctrl+Shift+R` |
| CSV를 엑셀에서 열면 한글이 깨짐 | 이 사이트에서 받은 CSV는 깨지지 않음. 직접 만든 CSV는 "CSV UTF-8"로 저장 |

오류가 계속되면 브라우저에서 `F12` → **Console** 탭의 빨간 글씨를 확인하면 원인을 찾는 데 도움이 됩니다.

## 7. 보안 구조 요약
GitHub Pages에 올린 코드는 누구나 볼 수 있습니다. 그래서 **브라우저는 믿지 않고, 모든 검사를 데이터베이스에서** 합니다.

- 코드에는 공개용 **anon 키**만 있습니다. 실제 권한은 데이터베이스의 **RLS 정책**이 정합니다.
- 학생은 표에 직접 쓸 수 없고, 4개의 함수(`claim_student`, `toggle_like`, `add_comment`, `delete_my_comment`)로만 씁니다. 함수 안에서 투표 기간, 본인 여부, 글자 수(200자)를 다시 검사합니다.
- 같은 (학교, 학번)은 프로필이 하나뿐이고(DB unique 인덱스), 한 작품에 한 학생은 하트 1번뿐입니다(기본키).
- 학교 이름은 띄어쓰기와 끝의 "등학교/학교"를 무시하고 비교합니다. (`서울 고등학교` = `서울고`)
- 학생은 **자기 프로필만** 볼 수 있습니다. 하트 전체 개수는 함수로만 제공합니다.
- 댓글 작성자 이름은 **저장할 때 이미 가려서**(강*욱) 저장하므로, 학생에게 실제 이름이 전달될 길이 없습니다.
- 관리자는 `is_admin()`으로 판정합니다(관리자 명단의 이메일 + 익명 계정 아님). 관리자 등록은 가입 코드를 확인하는 함수로만 가능하며, 코드는 브라우저에서 읽을 수 없습니다.
- 결과 CSV는 `=`, `+`, `-`, `@`로 시작하는 값을 글자로 바꿔, 엑셀에서 수식으로 실행되지 않게 합니다.
